## Project Overview

Calcly is a responsive digital calculator developed using HTML, CSS
and JavaScript. It allows users to perform common arithmetic
calculations using either the on-screen buttons or a computer
keyboard.

The project focuses on clear interface design, calculation logic,
responsive layouts and the correct handling of invalid calculations.

## Project Objectives

The objectives of this project were to:

- Design an attractive digital calculator.
- Perform basic arithmetic calculations.
- Support decimal and percentage values.
- Handle invalid calculations safely.
- Add mouse and keyboard controls.
- Create a layout that works on different screen sizes.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal values
- Percentage conversion
- Positive and negative values
- Delete-last-digit control
- Clear and reset controls
- Previous-calculation display
- Selected-operator highlighting
- Keyboard input
- Division-by-zero error handling
- Responsive desktop, tablet and mobile layouts

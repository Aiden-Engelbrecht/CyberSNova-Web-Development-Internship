# FocusFlow Landing Page

## Project Level

Beginner Level — Project 1

## Internship Domain

Web Development

## Project Description

FocusFlow is a fictional productivity platform designed for students.
The landing page introduces the product, explains its main features,
presents student testimonials and displays the available pricing plans.

The purpose of this project was to create a modern and responsive
landing page using HTML and CSS.

## Features

- Responsive navigation bar
- Mobile navigation menu
- Hero section with call-to-action buttons
- Product features section
- Student testimonials
- Pricing section
- Call-to-action section
- Footer with navigation links
- Responsive desktop, tablet and mobile layouts
- Accessible semantic HTML structure

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Git and GitHub

JavaScript was used only to control the mobile navigation menu.
